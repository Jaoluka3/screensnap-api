# 🚀 Product Hunt Launch Guide

## Preparação (30 minutos)

### 1. Criar conta
1. Acesse https://www.producthunt.com
2. Faça login com Twitter ou GitHub
3. Complete o perfil

### 2. Criar listing
1. Clique **"Submit"** → **"Product"**
2. Preencha:

**Tagline:**
```
Screenshot & PDF as a Service — Capture any website with one API call
```

**Description:**
```
ScreenSnap API transforms any URL into a screenshot or PDF with a single API call. 

✅ One API call for PNG, JPEG, or PDF
✅ Full page screenshots with custom dimensions
✅ Free tier with 100 requests/month
✅ 50-70% cheaper than competitors
✅ Referral system — earn +50 requests per friend
✅ Telegram notifications for new signups

Perfect for developers, QA teams, and content creators who need automated website screenshots.

Try it free: https://screensnap-api.up.railway.app
```

**Website:**
```
https://screensnap-api.up.railway.app
```

**Topics:**
- Developer Tools
- APIs
- SaaS
- Productivity

**Makers:**
- Your Twitter/GitHub handle

### 3. Preparar assets
- **Logo:** 240x240 PNG (use o logo do ScreenSnap)
- **Screenshots:** 3-5 imagens mostrando:
  1. Landing page
  2. API playground
  3. Dashboard
  4. Exemplo de screenshot gerado
  5. Pricing page

### 4. Definir launch date
- **Melhor dia:** Terça, Quarta ou Quinta
- **Melhor hora:** 12:01 AM PST (3:01 AM Brasília)
- **Evite:** Segundas e Sextas

## Dia do Launch

### 1. Postar (12:01 AM PST)
1. Clique **"Publish"**
2. Compartilhe no Twitter com:
```
🚀 Just launched ScreenSnap API on @ProductHunt!

Screenshot & PDF as a Service — capture any website with one API call.

✅ Free tier: 100 requests/month
✅ 50-70% cheaper than competitors
✅ Referral system

Try it: https://screensnap-api.up.railway.app

#ProductHunt #SaaS #API #Developer
```

### 2. Engajar
- Responda TODOS os comentários em até 1 hora
- Seja útil e técnico
- Ofereça desconto para early adopters

### 3. Promover
- Compartilhe em:
  - Twitter
  - LinkedIn
  - Reddit (r/SaaS, r/webdev, r/programming)
  - Hacker News
  - Indie Hackers

## Métricas para acompanhar

- **Upvotes** — meta: 100+ no primeiro dia
- **Comments** — engajamento da comunidade
- **Website traffic** — visitors do Product Hunt
- **Signups** — conversão de visitors em users
- **Revenue** — primeiros pagamentos

## Pós-launch

1. **Agradeça** aos supporters
2. **Implemente feedback** recebido
3. **Publique updates** semanais
4. **Considere** ser "Product of the Day"

**Objetivo:** Top 5 do dia = 500+ visitors = 50+ signups = 5+ paying customers
